# Kapsule — Visual Design Constitution

## Purpose

This document defines the complete visual language of Kapsule.

It is NOT a product specification.

It is NOT an engineering document.

It only defines how Kapsule should look and feel.

Every screen must follow these principles.

---

# Design North Star

If Apple designed a premium personal digital vault in 2026,
what would it feel like?

Not futuristic.

Not flashy.

Not trendy.

Timeless.

Invisible.

Calm.

Trustworthy.

---

# Emotional Design

The interface should disappear.

The content should become the focus.

The product should reduce anxiety.

Every screen should feel slower emotionally,
while remaining technically fast.

Users should never feel overwhelmed.

# Avoid

Visual excitement.

Visual complexity.

Over-design.

Decoration.

Loud interfaces.

Technology-first feeling.

Everything should feel people-first.

---

# White Space

Whitespace is the primary design element.

Never fill empty areas just because there is space.

Breathing room creates trust.

Every card deserves space.

Every section deserves silence.

Large margins are encouraged.

Dense layouts are forbidden.

---

# Layout Rhythm

Use a consistent vertical rhythm.

Large section spacing.

Comfortable card spacing.

Generous page padding.

Nothing should feel compressed.

Never maximize information density.

Optimize for clarity instead.

---

# Typography

Typography creates hierarchy.

Not colors.

Not borders.

Not shadows.

Prefer:

Geist

Inter

SF Pro

Never use decorative fonts.

Never use condensed fonts.

Never use futuristic fonts.

Weights:

Regular

Medium

Semibold

Bold

Avoid excessive bold text.

Large headings.

Comfortable body text.

Readable line height.

---

# Color Philosophy

White is the primary color.

Not the accent.

Whitespace is more important than branding.

Color should communicate actions.

Never decoration.

Accent color must remain rare.

When everything is colorful,

nothing is important.

# Cards

Cards are containers.

Not decorations.

Large radius.

Soft elevation.

Minimal metadata.

No visual clutter.

No heavy borders.

No gradients.

No glass.

Content first.

Chrome second.

---

# Shadows

Soft.

Natural.

Almost invisible.

Never dramatic.

Never floating.

Never glowing.

---

# Borders

Hairline.

Subtle.

Used only when necessary.

Never thick.

Never dominant.

---

# Corners

Soft.

Consistent.

Do not mix multiple radius systems.

---

# Icons

Lucide only.

Outline only.

No filled icons.

No emoji.

Consistent optical size.

---

# Images

Images support content.

Images never dominate the interface.

Use large previews.

Avoid decorative illustrations.

---

# Buttons

Buttons should feel soft.

Not aggressive.

Not oversized.

Primary button appears only when needed.

Avoid multiple competing primary buttons.

---

# Inputs

Minimal.

Rounded.

Comfortable height.

Subtle borders.

Strong focus state.

---

# Lists

Comfortable spacing.

Clear hierarchy.

Easy scanning.

No unnecessary separators.

---

# Empty States

Should reduce anxiety.

Not entertain.

Helpful.

Simple.

Beautiful.

No cartoons.

No mascots.
