# Kapsule Screen Blueprints

This document defines every major screen.

It does not describe implementation.

It describes experience.

Every screen should feel calm, premium and effortless.

---

##############################################################
HOME
##############################################################

Purpose

The Home screen is the beginning of the user's digital life.

Not a dashboard.

Not a control panel.

Not a statistics page.

It should feel like opening a beautifully organized notebook.

---

User should immediately understand

Where they left off

What's important today

Recently opened items

Things requiring attention

---

Top Area

Large greeting.

Current date.

Optional subtle motivation.

Never oversized hero banners.

Never marketing content.

---

Search

Always visible.

Large.

Centered.

Easy to access.

Search is the primary interaction.

---

Continue Section

The very first content block.

Continue where you left off.

Show

Recent documents

Recent notes

Recent receipts

Recent subscriptions

Recent warranties

Maximum 5 items.

---

Recent Activity

Chronological.

Beautiful.

Minimal.

Not a timeline feed.

Just enough information.

---

Collections

Documents

Receipts

Subscriptions

Warranty

Bookmarks

Notes

Timeline

Displayed as elegant cards.

Not colorful tiles.

---

Suggestions

Only when useful.

Examples

Renew insurance

Warranty expires soon

Subscription renewal

Passport expires

Never fake suggestions.

Never marketing.

---

Bottom

Nothing.

Leave breathing room.

---

##############################################################
GLOBAL RULES
##############################################################

Every screen starts with whitespace.

Every page has one primary purpose.

Every interaction should require minimal thought.

No screen should resemble enterprise software.

No screen should resemble an admin dashboard.

Content always comes before controls.

Navigation should disappear.

The interface should feel expensive.

Users should trust the product within three seconds.
