# Kapsule — Design System

## Purpose

This document defines every reusable UI component.

Consistency is mandatory.

---

# Grid

8px spacing system.

4px for micro spacing.

16px standard spacing.

24px section spacing.

32–64px page spacing.

---

# Border Radius

Small

10px

Medium

16px

Large

24px

Cards

20–24px

Do not mix arbitrary radius values.

---

# Shadows

Soft.

Layered.

Minimal.

Never dramatic.

---

# Typography Scale

Display

48–64px

Heading

32–40px

Title

24px

Section

20px

Body

16px

Small

14px

Caption

12px

---

# Buttons

Primary

Filled

Accent color

Rounded

Medium height

Secondary

Neutral

Soft background

Ghost

No background

Text

Minimal

Danger

Muted red

Never oversized.

Never glossy.

---

# Inputs

Rounded.

Comfortable padding.

Visible focus.

Subtle border.

No harsh outlines.

---

# Search Bar

Large.

Centered.

Always easy to access.

Search is a first-class component.

---

# Cards

Cards contain content.

Padding:

24px

Large media

Rounded corners

Minimal metadata

Soft shadow

---

# Lists

Comfortable spacing.

Large click targets.

Easy scanning.

---

# Tables

Avoid whenever possible.

Prefer cards.

Only use tables for dense structured data.

---

# Modals

Centered.

Focused.

One task.

Easy dismissal.

---

# Sheets

Use for contextual actions.

Avoid replacing full pages unnecessarily.

---

# Toasts

Bottom right desktop.

Bottom mobile.

Short.

Clear.

Disappear automatically.

---

# Badges

Minimal.

Muted.

Never rainbow colors.

---

# Icons

Lucide.

Outline.

20–24px.

Consistent stroke.

---

# Avatars

Circular.

Minimal borders.

Initials when image unavailable.

---

# Dividers

Rarely used.

Whitespace is preferred.

---

# Tabs

Few tabs.

Clear labels.

No icons unless necessary.

---

# Navigation

Desktop

Left sidebar.

Clean.

Minimal.

Mobile

Bottom navigation or staggered menu.

Never hamburger-first.

---

# Component Philosophy

Components should disappear.

Content should dominate.

Components support the experience.

They never become the experience.
