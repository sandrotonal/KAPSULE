# Kapsule — Anti Patterns

These are forbidden.

Do not generate interfaces that resemble the following.

---

Admin Dashboard

Analytics Dashboard

Crypto Exchange

Trading Platform

ERP

CRM

POS

Developer Tool

IDE

Database Viewer

Windows Explorer

Google Drive Clone

Dropbox Clone

Finder Clone

Notion Clone

ClickUp Clone

Monday Clone

Jira Clone

---

Never create

Pie charts

Bar charts

Line charts

Metrics

KPIs

Statistics

Graphs

Revenue widgets

Analytics cards

Big numbers

Performance dashboards

Monitoring panels

Heatmaps

Activity graphs

---

Never use

Terminal styling

Monospace as primary font

Matrix aesthetics

Cyberpunk

Neon

Sci-fi

Retro computing

Dark hacker UI

Console windows

Code editor appearance

---

Never overuse

Borders

Badges

Pills

Tags

Labels

Icons

Accent colors

Drop shadows

Floating buttons

Gradient backgrounds

Glassmorphism

Noise textures

Blur for decoration

---

Avoid layouts that look like

Enterprise software

Internal company tools

Developer dashboards

Security consoles

File explorers

Control panels

Monitoring software

---

Do not create

Four-column dashboards

Dense grids

Tiny cards

Information overload

Twenty widgets on one screen

Complex filter panels

Nested sidebars

Nested navigation

Multiple toolbars

---

Avoid language like

System Status

Analytics

Performance

CPU

Memory

Monitoring

Logs

Terminal

Vault Statistics

Encryption Status

Storage Usage

Server

Nodes

Clusters

Infrastructure

---

Never prioritize

Features over clarity.

Technology over emotion.

Information over breathing room.

Power over simplicity.

Complexity over trust.

---

The interface must always feel like

A premium consumer product.

Not enterprise software.

Not an admin panel.

Not a developer tool.

Not a dashboard.
