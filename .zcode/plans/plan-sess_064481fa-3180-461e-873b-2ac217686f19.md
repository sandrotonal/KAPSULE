## FAZ 1 — Temel Düzeltmeler (sağlam zemin)

Kararlar: Accent = Apple mavisi, tüm uygulamayı Türkçeleştir, ölü kodu temizle, paylaşılan motion modülü kur.

### 1. Accent token çakışmasını çöz
- `tailwind.config.js`: `accent.DEFAULT` hardcoded `#4F46E5` → `var(--accent)` yap. `accent.muted`/`accent.soft` gibi alfa katmanları `color-mix` ile `--accent` üzerinden türet.
- `globals.css`: `::selection` ve `:focus-visible` outline'daki hardcoded `#4F46E5` → `var(--accent)`.
- `Sidebar.tsx`, `LineSidebar.tsx`, `lib/utils` shadow içindeki hardcoded `rgba(79,70,229,...)` / `rgba(0,122,255,...)` → accent token.
- Sonuç: tek accent kaynağı, karanlık mod düzgün çalışır.

### 2. Paylaşılan motion modülü
- Yeni `src/lib/motion.ts`: `stagger` (container/item variants), `springGentle`, `easeOutExpo`, `fadeUp` — HomeScreen'deki inline `stagger`'ı buradan import edecek şekilde refactor. Tüm ekranlar aynı fiziksel variant'ı paylaşır.

### 3. Ölü kod temizliği
- `HomeScreen.tsx`: unused import'lar (`Search`, `Activity`, `Zap`, `SlideArrowButton`, `formatDate`), `recentItems`, `suggestions`, `onOpenSearch` kullanılmıyor → kaldır. (Props imzasını koru, sadece usage temizle; `onOpenSearch`'ü gerçekten header'a bağlayacağım yerine kaldırma riski varsa kullan.)
- `SearchModal.tsx`: `ArrowRight` dead import; **`group-focus-within` blob bug'ını düzelt** (group ancestry).
- `DocumentsScreen.tsx`: `Filter` dead import.
- `SettingsScreen.tsx`: `Info` dead import.

### 4. İkinci sınıf ekranları Tier-A seviyesine yükselt
**ReceiptsScreen.tsx + BookmarksScreen.tsx + SettingsScreen.tsx** için:
- İngilizce → Türkçe tüm metinler.
- Başlık ölçeği: `text-2xl` → `text-4xl tracking-tight`, root `space-y-7` → `space-y-10`.
- Add butonu: `variant="secondary" size="sm"` → `primary size="md" rounded-full px-6`.
- Search input'a `max-w-md` + `h-12 rounded-2xl`.
- Bookmarks grid gap `gap-3` → `gap-6`.
- Bookmarks empty state'i büyüt (`w-10 h-10` → `w-20 h-20 rounded-[2.5rem] py-24`).

### 5. Eksik empty state'leri ekle
- **ReceiptsScreen**: hiç empty state yok → ekle.
- **TimelineScreen**: events boşsa → "Henüz olay yok" + ikon.
- Empty state bileşenini paylaşılan bir `<EmptyState>` olarak `components/ui` altında oluştur (tüm ekranlar uses).

### 6. Ekran bazlı bug düzeltmeleri
- **SubscriptionsScreen**: hardcoded `'65%'` bar → gerçek `monthlyTotal`'a göre oranla; `subs.sort` → kopyala sonra sort (in-place mutasyon fix); `localStorage.setItem` → `VaultStorageService` üzerinden.
- **TimelineScreen**: hover-only `opacity-0 group-hover` aksiyonu → dokunmatikte de görünür yap (`opacity-100` default veya her zaman görünür küçük chevron).

### 7. Doğrulama
- `npx tsc --noEmit` ve `npx vite build` ile temiz derleme.
